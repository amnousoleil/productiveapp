🔧 Débloquer ProductiveApp

Écran noir ? Voici 3 méthodes pour résoudre le problème

✨ Méthode 1 : Nettoyage Automatique (Recommandée)

  1. Cliquez sur le bouton ci-dessous
  2. Attendez que le nettoyage se termine (3-5 secondes)
  3. Vous serez redirigé vers l'application
🚀 Nettoyer Automatiquement

🛠️ Méthode 2 : Via les Outils Développeur

  1. Appuyez sur F12 pour ouvrir les DevTools
  2. Allez dans l'onglet Application (ou Storage)
  3. Dans le menu de gauche, cliquez sur Service Workers
  4. Cliquez sur Unregister pour chaque Service Worker listé
  5. Cliquez sur Clear storage puis Clear site data
  6. Fermez les DevTools et appuyez sur Ctrl+Shift+R (hard refresh)

🕵️ Méthode 3 : Mode Navigation Privée

  1. Fermez TOUS les onglets de ProductiveApp
  2. Ouvrez une fenêtre de navigation privée (Ctrl+Shift+N sur Chrome/Edge)
  3. Allez sur https://giri-app.com
  4. L'application devrait fonctionner sans cache
  5. Une fois que ça marche, retournez en mode normal

Note : Si le mode privé ne fonctionne pas, utilisez la Méthode 1 ou 2.

Une fois le nettoyage terminé :

🏠 Aller à l'Application
